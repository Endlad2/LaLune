# La Lune API Server

API сервер для управления WDTT
```

### Linux/Mac

```
chmod +x
```

## Запуск

```
./la-lune-server
```

Сервер запустится на `http://localhost:7419`

## API Эндпоинты

### GET /api/start

Запускает WDTT клиент

Параметры:

- peer - IP адрес сервера
- vk - хеши через запятую (1-4)
- n - мощность (9-109)
- listen - адрес и порт для прослушивания

### GET /api/start-tunnel

Запускает WireGuard туннель

Параметры:

- config_file - полный путь к конфигу

### GET /api/logs

Получает логи от бинарника

### GET /api/logs/write

Записывает логи

Параметры:

- text - текст для записи
- base64 - base64 текст для записи

### GET /api/disconnect

Останавливает процесс и закрывает туннель
