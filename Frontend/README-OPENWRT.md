# OpenWRT в LaLune Frontend

Фича «Подключить OpenWRT» позволяет переключить все API-запросы
с локального `127.0.0.1:1062` на IP роутера (например `192.168.1.1:1062`).
При этом UI работает как с обычным бэкендом — просто данные идут с роутера.

## Как пользоваться

1. **Настройки → Экспериментальное → Роутеры → «Подключить OpenWRT»**.
2. Откроется модалка:
   - Сверху «Ищем роутеры…» и список найденных `192.168.X.1:1062`.
   - Снизу кнопка **«Ввести IP роутера вручную»** — можно добавить
     роутер по IP напрямую.
3. Клик по роутеру → диалог **«Установить соединение?»**.
4. После подтверждения:
   - Все API-запросы идут на роутер.
   - Сверху появляется **зелёный баннер**
     «Подключено к роутеру {имя роутера}».
   - В бэкенде сохраняется `activeRouter` (SharedPreferences).
5. Отключение:
   - Клик по баннеру, или
   - **Настройки → Экспериментальное → Роутеры → Отключить**.
   - API возвращается на `127.0.0.1:1062`, баннер исчезает.
   - **Процессы на роутере НЕ убиваются** — `csqtt-client-aarch64`
     и `lalune-openwrt-backend` продолжают работать.

## Что происходит при подключении

1. `RouterNotifier.connect()`:
   - `GET http://<ip>:1062/ping` — проверка доступности.
   - `GET http://<ip>:1062/core/protocols` vs локальный `GET /core/protocols`.
     Если нет пересечения — подключение блокируется.
   - `GET /vk/token/raw` (локально) → `POST http://<ip>:1062/vk/token/submit`.
     **Наш VK-токен передаётся на роутер**, чтобы он мог создавать звонки.
   - `apiClient.setBaseUrl(ip)` — все последующие запросы идут на роутер.
2. Все `*_notifier.dart` подписаны на `apiClient.baseUrlChanges`
   и перезагружают данные при смене хоста:
   - `configs_notifier` → `reload()`
   - `settings_notifier` → `reload()`
   - `vpn_notifier` → переподключение SSE + `_refresh()`
   - `logs_notifier` → очистка + переподключение SSE + `_refresh()`
   - `vk_notifier` → `_refresh()`

## Ограничения

- **VK-токен**: при подключении к роутеру наш токен передаётся роутеру.
  Если токен на устройстве отсутствует — передать нечего.
- **Скан**: перебор 256 адресов × 600 мс / 24 параллельно ≈ 7 секунд.
  Можно отменить, закрыв модалку.
- **SSE**: переподключается автоматически через `SseClient`, который
  подписан на `baseUrlChanges`.
- **Настройки не сохраняются на роутер автоматически**: после подключения
  нужно зайти в «Настройки» и нажать «Сохранить», чтобы записать текущие
  значения в `settings.json` роутера.

## Дизайн-решения

- Роутер передаёт свой `hostname` в `/ping`, он показывается в списке.
- Если `hostname` пустой — показывается IP.
- В `savedRouters` сохраняются ВСЕ добавленные вручную роутеры,
  даже после disconnect.
- Активный роутер хранится отдельно в `activeRouter` и в
  SharedPreferences (`lalune.active_router`).
